# Cotrim Tranças

App de agendamento da trancista Aline.

- `/` app das clientes: catálogo de modelos, agendamento só aos fins de semana, combinados, Pix do sinal e avaliações.
- `/painel` painel da Aline (login): pedidos, ajustes de preços e agenda, aprovação de avaliações.

Dados no Supabase (projeto `cotrim-trancas`). Site estático publicado no Vercel.
O código-fonte fica em `src/`; os arquivos da raiz são gerados por `src/build_vercel.py`.

Desenvolvido pela [QuasarTcode](https://www.quasartcode.com.br).
