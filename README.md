# Cotrim Studio Tranças

App de agendamento da trancista Aline.

- `/` app das clientes (cotrim-trancas.vercel.app): catálogo de modelos, agendamento só aos fins de semana, combinados, Pix do sinal e avaliações.
- `adm/` painel da Aline (login), publicado como site separado em cotrim-trancas-adm.vercel.app: pedidos, ajustes de preços e agenda, aprovação de avaliações.

Dados no Supabase (projeto `cotrim-trancas`). Site estático publicado no Vercel.
O código-fonte fica em `src/`; os arquivos da raiz são gerados por `src/build_vercel.py`.

Desenvolvido pela [QuasarTcode](https://www.quasartcode.com.br).
